DETAILED FINDINGS & THREAT MODELING (1)

1. [T1-F05] DNS resolver exposed on management interface
   Severity      : Low-Medium | Status: Confirmed
   Weakness      : CWE-345 (Insufficient Verification of Data Authenticity) / CWE-400 (Resource Amplification)
   Category      : Network-Level Exposure / DNS Behavior
   Module        : Network Discovery
   Threat Vector : In a threat environment, an outdated or misconfigured DNS daemon (such as legacy dnsmasq versions) can be targeted for DNS Cache Poisoning (DNSpooq series) or DNS Spoofing attacks. An attacker can forge DNS responses to poison the repeater's cache, redirecting all connected users from legitimate domains (such as banking or social media) to malicious phishing servers.
   Impact        : The device runs an active DNS resolver which may redirect setup queries or expose internal DNS resolution.
   Remediation   : Restrict DNS exposure to required client interfaces only and validate redirect behavior.
   Hardening     :
     * 1. Upgrade dnsmasq to version 2.83 or later to mitigate DNSpooq vulnerability advisories (CVE-2020-25681 through CVE-2020-25687).
     * 2. Configure the DNS server to listen exclusively on the internal LAN interface (bind-interfaces).
     * 3. Enable source port randomization and DNSSEC query verification in dnsmasq configuration.
